## 今までやったこと

### SHABET（チーム開発・リーダー）
「顔見知りから親友へ仲を深める」をコンセプトにしたカードゲームアプリ。12人のチームで開発しています。
- 技術：Go（バックエンド）／Flutter（モバイル）／TypeSpec → OpenAPI／WebSocket
- 担当：サービスリーダー、プロダクトオーナー兼スクラムマスター。タスクの割り振り・進捗管理・レビュー

### ミライケータイプロジェクト
大学のプロジェクト学習。SHABET を含む複数サービスを開発するプロジェクトで、オープンキャンパス用のポスター・スライド制作や発表を担当しました。

### [HOPE 課題締切通知 Bot](https://github.com/KurenNagata/hope-notifier)（個人開発）
大学の学習管理システム（HOPE / Moodle）の未提出課題を、締切前に Discord へ通知する Bot。
- 技術：Go／Docker／Linux サーバー（Debian）で常時稼働
- 機能：朝・夜の定時通知（夜は当日残りと翌日締切の課題を通知）、Discord で依頼した時刻に知らせるリマインド機能
- Claude（AI）を用いて開発

### [LearnCode](https://github.com/KurenNagata/LearnCode)（個人開発）
プログラミング言語を学ぶための学習アプリ。Claude（AI）を用いて開発しました。

### ポートフォリオサイト（個人開発）
API をテーマにしたデザインのポートフォリオサイト。HTTP メソッド風のラベルやエンドポイント風のナビゲーション、`profile.json` のタイピングアニメーションを取り入れています。Claude（AI）を用いて開発しました。
